处理哪些数据、为什么处理

  • 公共排行榜参加（同意，GDPR 第 6(1)(a) 条）：随机参赛编号、玩家自选昵称、各小游戏最佳成绩、身份创建及修改时间，以及用于恢复身份的令牌摘要。昵称、公开编号、成绩、名次与公开战绩卡会向所有访客显示。你可以拒绝或之后撤回同意；这不影响本机游戏。
  • 安全与公平维护（合法利益，GDPR 第 6(1)(f) 条）：有限的成绩会话、提交幂等键、原因码及管理员审核记录，用于阻止重放提交、处理异常成绩及维护活动榜单。为能在需要时复核服务端重算，最近三次十秒计时尝试与十次投篮时间会短期关联到已有的随机参赛身份；完全相同的游戏事件另保存短期摘要，用于识别跨挑战重复提交。这些信息不包含 IP、设备指纹或额外个人资料。正常会话和摘要在定时清理中约 24–48 小时内删除；进入人工复核的游戏事件明细保留至处理完成或最迟 30 天清理。只有服务端重算不一致、短期重复事件等独立风险信号才会暂缓公开；成绩优秀本身不会触发审核。浏览器游戏仍无法由服务器独立证明真实点击过程；系统不会对玩家作出具有法律或类似重大影响的自动决定。
  • 隐私请求（遵守数据保护义务，GDPR 第 6(1)(c) 条）：请求类型、可选的公开参赛编号、你自愿填写的说明、请求状态及回复。请勿填写敏感信息或他人的信息。访问码只显示一次；服务端只保存它的 SHA-256 摘要。控制者可以查看请求，提交者凭请求编号与访问码查看处理状态和回复。
  • 举报：提交者的随机参赛身份、目标公开编号和有限的举报原因码；不提供自由文本。被举报玩家的数据来源是该玩家公开的榜单资料及其他玩家提交的举报。

排行榜昵称和成绩只为本次 Halloween Arcade 提供公开排名与分享。我们不要求真实姓名、邮箱、电话号码、学号或微信号；不使用 IP 作为玩家身份，不建立设备指纹，不提供广告追踪、公共聊天或公共用户画像。

必要服务商、公开范围与跨境处理

  • 公开访客：加入榜单后，所有人都能看到昵称、公开编号、名次、成绩以及通关状态；请使用不含个人信息的昵称。
  • Cloudflare：提供 Worker、D1 数据库及 Turnstile 验证。排行榜应用不把 IP 写入 D1，也不向 Siteverify 转发 IP；Cloudflare 仍可能为网络传输、安全和验证处理连接元数据。Cloudflare 全球网络可能涉及欧洲经济区之外的处理；其当前数据处理附录说明了适用于受限传输的欧盟标准合同条款及获取方式，详见Cloudflare 数据处理附录。
  • GitHub Pages：托管本网站。GitHub 说明 Pages 访问者的 IP 地址会为安全目的记录并保存；这些平台日志不进入本项目的排行榜数据库。平台自身的数据处理见GitHub 隐私声明。

除上述公开展示和服务商外，本项目不向广告商、论坛或其他项目提供排行榜数据。服务商在提供服务时可能使用其分包商；具体处理地点、平台级日志和适用的传输保障以各服务商当时的条款、隐私声明及数据处理文件为准。

保存期限、权利与选择

  • 玩家身份、公开昵称、成绩、恢复摘要及举报/审核数据计划保留至 2026-12-31；Europe/Rome 2027-01-01 00:00 的计划任务清理活动身份和成绩。普通游戏事件明细与去重摘要按上文短期清理，待审证据最长保留 30 天，管理员审核日志最长保留 90 天。你也可以提前删除自己的身份及成绩。
  • 隐私请求访问码只保存摘要。未结请求最迟在提交后 180 天清理；已回复或关闭的请求在处理完成后 90 天清理。
  • 在法律规定的条件下，你可以请求访问、更正、删除或限制处理，反对基于合法利益的处理，并在适用时请求数据可携；如果处理基于同意，你可以随时撤回同意，不影响撤回前的合法处理。
  • 你可以向意大利个人数据保护监管机构 Garante per la protezione dei dati personali 提出投诉：garanteprivacy.it ↗。
  • 提交排行榜所需的昵称和同意仅为可选榜单服务的必要条件；不提供时仍可玩本机游戏。没有法定或合同义务要求你参加。隐私请求中的公开编号和说明均可留空；无需创建账户或交付联系资料。
  • 通常会在收到数据权利请求后一个月内答复；如请求复杂或数量较多，法律允许在一个月内说明延期及理由。

可选的 Umami 访问统计

只有在你选择“允许匿名统计”后，本网站才会加载 Umami Cloud 统计脚本并发送统计请求。你可以拒绝；这不会影响地点指南、小游戏、排行榜或隐私请求。之后可以用页面底部的“统计偏好”撤回同意。撤回只停止后续收集，不会自动删除此前已进入 Umami 的统计记录。

  • 目的与法律依据：了解页面浏览、访问次数、外部流量来源，以及地图链接、Halloween Arcade 入口和合作商家链接的匿名点击次数；依据为你的同意（GDPR 第 6(1)(a) 条）。拒绝或撤回不会影响其他功能。
  • 发送内容：当前页面路径（不含查询参数和片段）、固定页面标题、浏览器语言、外部来源网站的域名，以及不带额外属性的固定点击事件名称。本网站不会把搜索词、表单内容、昵称、游戏成绩、恢复码、论坛内容或其他输入内容发送给 Umami；不设置自定义 Distinct ID，也不用于跨网站关联。
  • Umami 的匿名访客计算：按 Umami 文档，访客 IP 地址会被处理，用于请求传输、以网站 ID、IP、浏览器 User-Agent 与轮换盐生成匿名会话标识，并计算大致地区；User-Agent 还用于汇总浏览器、操作系统和设备类别。标准分析记录不把 IP 地址作为字段保存。Umami 或其基础设施提供方仍可能在独立的运维或安全日志中记录连接数据。该匿名标识不是绝对匿名保证，不会由本网站设置为跨站 ID。
  • 服务商与地区：Umami Software, Inc. 作为 Umami Cloud 服务提供方处理统计数据。本账户的分析存储区域为 EU；该区域选择不代表所有 CDN 路由、安全支持和运维日志都仅在 EU 处理。详见 Umami 隐私政策、数据处理协议及指标与访客计算说明。
  • 保存期限：统计记录按 Umami Cloud 账户实际方案的保存期限管理；Umami 当前公开说明为 Hobby 方案 6 个月、Pro 方案 2 年、Business 方案 5 年。控制者尚未在账户账单设置中确认当前方案，因此此处不声称某个具体期限适用于本账户；你可以通过页面底部的隐私偏好撤回之后的统计同意，或使用下方私密请求渠道提出数据权利请求。
  • 本机偏好：同意或拒绝选择保存在当前浏览器的 localStorage，不包含身份信息，也不会发送给 Umami。清除浏览器站点数据会清除该选择；更换浏览器或设备时需要重新选择。

Umami 官方说明其跟踪器不使用 Cookie；本网站仍采用主动同意控制。更多数据处理权利、数据控制者身份与私密联系渠道见本页其他部分。
